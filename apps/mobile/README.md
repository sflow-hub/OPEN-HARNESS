# Native client candidate

Expo/React Native iOS and Android source clients share the authenticated cloud contracts. Sign-in opens the system browser and exchanges a PKCE code; rotating native session tokens and unsent goals use the platform secure store. The app supports workspace selection, task messages, decisions, connected-action review, responsibilities, shared artifacts, app authorization through a browser handoff, desktop preview/input and a live desktop web handoff. Store purchases are credited only after server verification against the selected workspace. No coordinator operator token or platform model-provider key is given to the client.

Install with `npm ci` in this directory. Set `EXPO_PUBLIC_OPEN_HARNESS_ORIGIN` to the authenticated HTTPS service, then run `npm start`. `npm run typecheck` checks native source and `npm run export` creates the two JavaScript bundles. A development client is required for billing and platform push; Expo Go is not a production acceptance target. `eas.json` supplies development, preview and production profiles, with no signing credentials committed. Configure the application identifiers, EAS project, Apple/Google signing and store accounts explicitly before building. Native package versions are pinned in this directory’s lockfile.

Provide the server with APNs team/key/topic and private key, or its FCM service account, and use the notification outbox’s test action. Never place those credentials in Expo public variables. Purchases require the server’s Apple root certificates/bundle ID/app ID and Google Play service account/package ID, plus approved products. Native model usage, spending limits and membership controls are also available through the authenticated browser workspace.

JavaScript exports and typechecking do not establish signed installation, native SDK linking, physical-device OAuth/2FA, background delivery, store acceptance or desktop responsiveness. Run the physical iOS and Android matrix in `docs/EXPERIENCE_ACCEPTANCE.md`; keep test and production billing environments separate. Screenshots remain the explicit fallback for runners without streaming support.

# Hermes Agent attribution

Open Harness integrates Hermes Agent as an external runtime. Hermes Agent is
copyright Nous Research and contributors and is distributed under the MIT
License. The pinned source is fetched from
https://github.com/NousResearch/hermes-agent at commit
`939e45c91d751fadd94dcd1b873ac3cb44846213` during the container build.

Open Harness does not modify Hermes's reasoning loop. Its control service uses
Hermes's documented TUI gateway JSON-RPC interface.

## Deliberate limits of this candidate

- Managed cloud has a provider interface, durable lifecycle jobs and deployment reference; it has **no production VM provisioning adapter**. Selecting that provider is a pre-launch decision, followed by adapter implementation and acceptance.
- Remote human access requires authenticated HTTPS. Shared authenticated workspaces currently reject outbound runners that cannot renew their original human actor lease; local-owner remote runners remain supported with explicit capability negotiation.
- Included model usage currently accepts text/tool requests. Unsupported multimedia and remote runner model leases fail explicitly. User-provided keys remain available without a managed account.
- Prewarming is opt-in and limited to one clean, private, local, BYOK runtime without a desktop or shared browser. It expires after five minutes. Selected-folder admission always performs fresh mount verification.
- Connection subscriptions use bounded polling with durable cursors and resynchronization, rather than provisioning Google/GitHub push-watch channels.
- Tauri retains the local-owner desktop experience; a dedicated managed native sign-in flow still needs implementation and platform acceptance. Managed web and Expo clients use the new authenticated contracts.
- Portable backups currently support 256 MB total, 10,000 files, 128 MB SQLite and 16 MB per other file. Managed credential stores, browser profiles, pending pairing codes and webhook secrets are omitted or invalidated. Restored accounts need authorization and routines stay paused.
